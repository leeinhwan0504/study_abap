```abap
*&---------------------------------------------------------------------*
*& Report Z01_01
*&---------------------------------------------------------------------*
*&
*&---------------------------------------------------------------------*
REPORT Z01_01.


* 날짜 타입 변수를 선언하여 sy-datum 값을 할당한다.
DATA(gv_date) = sy-datum.   " 시스템 변수. 오늘 날짜
WRITE: / gv_date.

* 날짜 타입 변수에 숫자를 더하면 일(Day) 단위로 계산.
gv_date = gv_date + 3.
WRITE: / gv_date.

* 시간 타입 변수를 선언하여 sy-uzeit 값을 할당한다.
DATA(gv_time) = sy-uzeit.   " 시스템 변수. 현재 시간
WRITE: / gv_time.

* 시간 타입 변수에 연산을 수행하면 초(second) 단위로 계산된다.
gv_time = gv_time - 60.
WRITE: / gv_time.
```
