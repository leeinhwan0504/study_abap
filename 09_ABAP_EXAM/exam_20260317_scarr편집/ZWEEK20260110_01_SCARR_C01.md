CLASS lcl_event_receiver DEFINITION.
  PUBLIC SECTION.
    METHODS : handle_double_click
      FOR EVENT double_click OF cl_gui_alv_grid         " cl_gui_alv_grid 클래스의 double_click 메소드를 넣는다. 이벤트를 넣는다
      IMPORTING e_row                                   " 리턴 값. 선택된 행, 열
                e_column.
ENDCLASS.
*--------------------------------------------
* 클래스 구현

CLASS lcl_event_receiver IMPLEMENTATION.
  METHOD handle_double_click.


* 내가 선택하는 alv .... line

    IF r1 ='X'.
      DATA: tmp_GT_ZSC LIKE LINE OF GT_ZSC.                   " LIKE LINE OF는 테이블 구조를 행 구조를 만들때 사용.

      READ TABLE GT_ZSC INDEX e_row-index INTO tmp_GT_ZSC.    " 더블 클릭한 행번호로 내가 출력한 테이블에서 읽어온다.
      tmp_GT_ZSC-carrname = 'ZSCARR'.                         " SE11의 첫번째 필드에 테이블 이름 ZSCARR 을 넣는다.
      set PARAMETER ID 'DTB' FIELD tmp_GT_ZSC-carrname.
    ELSEIF r2 ='X'.
      DATA: tmp_GT_ZSCARR LIKE LINE OF GT_ZSCARR.

      READ TABLE GT_ZSCARR INDEX e_row-index INTO tmp_GT_ZSCARR.
*      tmp_GT_ZSCARR-carrname = 'ZSCARR'.
      set PARAMETER ID 'DTB' FIELD tmp_GT_ZSCARR-carrname.    " SE11의 첫번째 필드에 테이블 이름 carrname 을 넣는다.
    ENDIF.

    call TRANSACTION 'SE11' WITHOUT AUTHORITY-CHECK.

  ENDMETHOD.
ENDCLASS.
