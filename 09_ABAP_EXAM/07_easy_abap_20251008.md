```abap
*&---------------------------------------------------------------------*
*& Report Z01_01
*&---------------------------------------------------------------------*
*&
*&---------------------------------------------------------------------*
REPORT Z01_01.


DATA: gv_text TYPE c LENGTH 10.

* CONV 옵션을 사용하면, 원하는 타입으로 변수 타입을 변경할 수 있다.
* 문자형 변수이지만, 1자리 소수점을 표현해서 자동 타입 변환을 수행한다.
gv_text = | { 2 / 3 DECIMALS = 1 } |.
WRITE: / gv_text.
```

```abap
*&---------------------------------------------------------------------*
*& Report Z01_01
*&---------------------------------------------------------------------*
*&
*&---------------------------------------------------------------------*
REPORT Z01_01.


DATA: gv_text TYPE c LENGTH 10.

* CONV 옵션을 사용하면, 원하는 타입으로 변수 타입을 변경할 수 있다.
* 문자형 변수이지만, 1자리 소수점을 표현해서 자동 타입 변환을 수행한다.
* CONV 구문을 이용해 타입 변환을 실행해야 한다.
gv_text = | { CONV decfloat34( 9 / 3 ) DECIMALS = 1 } |.
WRITE: / gv_text.
```
